Вариант №19: эмулятор командной строки UNIX-подобной ОС.

---

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим
интерфейсом (GUI) на основе Tkinter. Работает с виртуальной
файловой системой (VFS), загружаемой из JSON-файла в оперативную
память. Все изменения VFS происходят только в памяти, файл
на диске не меняется.

### Реализованные возможности

- Графическое окно с заголовком из реальных данных ОС:
  `Эмулятор - [username@hostname]`.
- Приглашение с текущей папкой: `user@host:/home$`.
- Простой парсер: разбор ввода на команду и аргументы
  по пробелам.
- Параметры командной строки (`--vfs`, `--log`, `--script`)
  с отладочным выводом при запуске.
- Логирование вызовов команд в XML с именем пользователя
  и временем события.
- Стартовые скрипты: показывают ввод и вывод,
  останавливаются на первой ошибке.
- Команды: `ls`, `cd`, `pwd`, `tree`, `rmdir`, `cp`, `exit`.

### История этапов

- Этап 1: REPL-прототип, заглушки `ls`/`cd`, команда `exit`.
- Этап 2: параметры запуска, XML-лог, стартовые скрипты.
- Этап 3: загрузка VFS из JSON в память, обработка ошибок.
- Этап 4: настоящие `ls`/`cd`, новые `pwd`/`tree`.
- Этап 5: `rmdir` и `cp` с изменением VFS только в памяти.

## 2. Параметры командной строки

```bat
run.bat --vfs <путь_к_vfs.json> --log <путь_к_логу.xml> --script <путь_к_скрипту.txt>
```

| Параметр   | Описание                                              |
|------------|-------------------------------------------------------|
| `--vfs`    | Путь к JSON-файлу виртуальной файловой системы        |
| `--log`    | Путь к XML-файлу лога вызовов команд                  |
| `--script` | Путь к стартовому скрипту с командами эмулятора       |

---

## 3. Поддерживаемые команды

| Команда      | Описание                                                        |
|--------------|-----------------------------------------------------------------|
| `ls [путь]`  | Содержимое папки VFS (папки помечаются `/`)                     |
| `cd <путь>`  | Смена папки (поддержка `.`, `..`, абсолютных и относительных путей) |
| `pwd`        | Вывод текущей папки                                             |
| `tree [путь]`| Дерево папок и файлов                                           |
| `rmdir <путь>` | Удаление пустой папки                                         |
| `cp <откуда> <куда>` | Копирование файла (новое имя, внутрь папки, с перезаписью) |
| `exit`       | Завершение работы эмулятора                                     |

Ошибки в стиле UNIX: `no such file or directory`,
`not a directory`, `directory not empty`,
`too many arguments`, `unknown command`.

## 6. Примеры использования

```bat
run.bat --vfs vfs_stage5.json --log log.xml --script start_stage5.txt
```

Интерактивный сеанс:

```
user@host:/$ ls
readme.txt empty/ docs/
user@host:/$ cp readme.txt copy.txt
user@host:/$ ls
readme.txt empty/ docs/ copy.txt empty_copy.txt
user@host:/$ rmdir empty
user@host:/$ rmdir docs
rmdir: cannot remove '/docs': directory not empty
user@host:/$ cd /readme.txt
cd: not a directory: /readme.txt
user@host:/$ exit
exit
```

Пример лога `log.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<log>
  <event>
    <user>nikita</user>
    <time>2026-09-28 10:00:00</time>
    <command>ls</command>
    <output>readme.txt home/</output>
  </event>
</log>
```
